# OpenClaw: Telegram AI Assistant

Развёртывание персонального AI-ассистента на Ubuntu 24.04
в Docker Compose с подключением Telegram.

## Что реализовано

- OpenClaw Gateway работает в Docker.
- Telegram-бот подключён, доступ пользователей — через pairing.
- AI подключён через авторизацию ChatGPT.
- Создан персональный SOUL.md: русский язык, краткие ответы,
  проверка фактов и подтверждение перед опасными действиями.
- Настроено восстановление SSH-туннеля через systemd.
- Для контейнера установлена политика restart: unless-stopped.

## Схема подключения

Gateway → SSH-туннель → Squid на сервере в Казахстане → Telegram API / AI.

Для приложения Telegram дополнительно настроен
Dante SOCKS5 с авторизацией по логину и паролю.

Системный VPN для этих подключений не используется.

## Проверка

- Получены ответы бота в Telegram.
- Сравнены внешние IP прямого подключения и подключения через прокси.
- Доступ к прокси проверен из контейнера Gateway.
- В журнале Squid подтверждены подключения к Telegram API и ChatGPT.
- В журнале Dante подтверждены подключения клиента Telegram.

Тестирование проводилось вне России.
Доступность из российских сетей отдельно не проверялась.

## Основная техническая задача

Настройка доступа Docker-контейнера к прокси через SSH-туннель.
Туннель привязан к адресу Docker-моста, а Gateway настроен
на использование прокси. Маршрут проверен по IP и журналам.

Для настройки и диагностики использовался ChatGPT.

## Содержимое репозитория

README.md — описание выполненной работы.
SOUL.md — персональная инструкция ассистенту.

Пароли, токены, приватные ключи и файлы авторизации не публикуются.
